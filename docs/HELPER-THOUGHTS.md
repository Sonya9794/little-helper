# Helper Thoughts and collapsible Settings

Settings contains four keyboard-accessible disclosure sections: Save a Prompt, Mode, Helper Thoughts, and Chess Difficulty. They start collapsed; open/closed choices survive refreshes within the app session. Chess's Edit shortcut opens its section automatically. Prompt drafts remain intact while changing other settings. These disclosure choices do not need a new storage file.

Helper Thoughts starts **off**. Off means no visible bubble and no scheduled appearance. Jokes, Fun Facts, and Motivational Quotes can be selected independently. If all are off, no bubble is scheduled even with the master switch on. Changing these preferences cancels any current bubble and starts a new wait if applicable.

While enabled with at least one category, a native monotonic timer waits a randomly chosen whole-minute interval between the configured minimum and maximum (default 3–10 minutes) before presenting one small ellipsis thought. Click it to reveal one short, randomly selected message from the enabled categories. Thirty short texts are bundled locally (ten per category). Nothing reads websites or contacts a service. Pop or Escape clears it and starts the next random wait. Only one thought is pending at a time; messages do not accumulate. An ignored mini bubble disappears two minutes after it first becomes visible, then starts a fresh wait in the configured interval. Clicking it reveals the message and cancels that expiry; a revealed message stays until dismissed or disabled. Quit restarts the wait on the next launch, while preferences persist. Tray minimization hides the bubble and cancels an unfinished wait; restoring starts a fresh wait, or restores a thought already pending. Sleep may delay an appearance; there is no catch-up burst.

The thought uses a separate small native window, so it does not share the mascot's input region. Its rendered cloud alpha defines Windows hit testing, including transparent corners and gaps. A native move handler follows dragging and DVD movement immediately. Placement tries beside the mascot, then above/below, clamps to the current monitor's work area, and never overlaps the sprite. If there is no safe room, it stays hidden until there is room. It is created without keyboard focus. Thoughts temporarily hide while the mascot menu or Settings panel is open, so they cannot cover those controls; the pending thought resumes when those close. Clicking the mascot still opens its menu and dragging still moves it. The thought can be revealed/dismissed without moving the mascot.

On macOS, where this pilot still lacks a native alpha-hit adapter, the thought uses an ordinary decorated window rather than an invisible rectangular overlay. The existing mascot remains decorative. This fallback is designed to compile from the same source but requires a Mac to build and visually test.

Preferences use human-readable `helper-thoughts.json` in the app-data directory:

- Windows: `%APPDATA%\com.sonya9794.little-helper\helper-thoughts.json`
- macOS: `~/Library/Application Support/com.sonya9794.little-helper/helper-thoughts.json`

Missing data starts off. Unsupported/malformed/unreadable files surface a local error and block writes to that file. Updates use the same atomic storage helper as other local data. Neither pending messages nor timing are written to disk. The file is ignored by Git.

`src-tauri/src/thoughts.rs` owns preferences, native timing, pending/revealed state, and monitor-safe following. `src/thought-model.ts` owns offline content and selection. `src/thought-ui.ts` renders the cloud, alpha, and controls; it polls as a fallback to native appearance events, without replacing keyboard controls on each poll. `src/thought-settings.ts` renders toggles. Existing scene/hit-mask code is reused without altering the mascot artwork or hit region.

## Manual Windows checks

- With a fresh profile, verify all Settings sections are collapsed. Open Helper Thoughts: the master toggle is off; no bubble should appear after ten minutes. Open/close sections using mouse and keyboard. Edits or window focus refreshes must retain open sections and prompt drafts. Chess Edit must open Chess Difficulty.
- Enable only Jokes. After a wait in the selected interval, click the ellipsis: only a joke should appear. Repeat with Fun Facts and Motivational Quotes separately. Select Pop to start a new wait. Ignoring the mini bubble for two minutes must hide it and start a fresh configured wait. Clicking before expiry must reveal the message and keep it visible beyond that two-minute boundary. No bubbles should stack.
- Turn the feature off with an ellipsis or message visible: it disappears immediately and stays absent. Enable it but turn all categories off: no bubble or appearance timer. Restart and confirm preferences persist.
- While a thought is visible, click and drag the mascot independently. Verify the thought follows, does not cover the sprite, and uses its own input region. Test DVD movement, screen edges, negative monitor coordinates, mixed DPI, and a changed monitor layout. Transparent bubble pixels must pass through on Windows.
- Minimize to tray: both windows disappear. Restore: no accumulated messages. Check sleep/resume and quit/relaunch. Appearance should not steal focus from another app.
- With the app closed and a backup available, corrupt the settings file. Restart: show a local error and preserve its bytes, including after attempted setting edits. Restore the backup afterward.

Run `npm run check` and `npm run build`. Unit tests cover off/all-off behavior, category selection, wait bounds, native waiting/dismissal/pause logic, preference persistence/errors, and non-overlapping edge placement.

Native timing chooses whole minutes inclusively between the endpoints. Pointer changes save on release; canceled drags restore the old values.
